支持这个项目

Text Wallpaper 是一款由一个人开发的免费、注重隐私的应用。捐款用来支付服务器账单，让应用对所有人保持免费。捐款完全自愿：捐与不捐，应用都一样用。

为什么需要捐款？

这里没有账号系统，也不出售或分享任何数据。我只保留匿名的使用统计：知道哪些功能被用了，但不知道是谁在用。没有广告，也没有付费版本，所有功能对所有人免费。广告或订阅只会让应用变得更糟，所以我不做。

这是一个单人项目。我有一份普通的工作，也有家庭，这个应用是我在业余时间做的。服务器每个月都要花真金白银，一直是我自己在付。捐款能让应用继续在线、继续免费。

这个应用也在 GitHub 上开源，任何人都可以查看代码。

有什么功能想法？

结账页面有一个可选的“功能建议”栏，把你的想法写在那里。每一条我都会看，在决定下一步做什么时，捐款人的想法会得到额外关注。
