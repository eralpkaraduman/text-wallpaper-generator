Dukung Proyek Ini

Text Wallpaper adalah aplikasi gratis dan privat yang dibuat oleh satu orang. Donasi dipakai untuk membayar tagihan server dan menjaga aplikasi ini tetap gratis untuk semua orang. Donasi sepenuhnya opsional — aplikasinya bekerja sama saja, donasi atau tidak.

Donasi lewat Stripe ❤

Kenapa donasi?

Tidak ada akun, dan tidak ada data yang dijual atau dibagikan. Saya hanya menyimpan hitungan pemakaian anonim: fitur mana yang dipakai, tapi bukan siapa yang memakainya. Tidak ada iklan dan tidak ada versi berbayar. Semua fitur gratis untuk semua orang. Iklan atau langganan hanya akan membuat aplikasi ini lebih buruk, jadi saya tidak memakainya.

Ini proyek satu orang. Saya punya pekerjaan biasa dan keluarga, dan saya mengerjakan aplikasi ini di waktu luang. Server butuh biaya sungguhan setiap bulan, dan saya bayar sendiri. Donasi membuat aplikasi ini tetap online dan gratis.

Aplikasi ini juga open source di GitHub, jadi siapa pun bisa membaca kodenya.

Punya ide fitur?

Di halaman pembayaran ada kolom opsional “permintaan fitur”. Tulis idemu di sana. Semuanya saya baca, dan ide dari para donatur mendapat perhatian ekstra saat saya memilih fitur berikutnya.
