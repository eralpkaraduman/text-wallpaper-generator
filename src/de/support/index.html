Dieses Projekt unterstützen

Text Wallpaper ist eine kostenlose, private App, gemacht von einer einzelnen Person. Spenden bezahlen die Serverrechnungen und halten die App für alle kostenlos. Spenden ist freiwillig — die App funktioniert genau gleich, ob du spendest oder nicht.

Über Stripe spenden ❤

Warum Spenden?

Es gibt keine Konten, und nichts wird verkauft oder weitergegeben. Ich behalte nur anonyme Nutzungszahlen: welche Funktionen genutzt werden, aber nicht von wem. Es gibt keine Werbung und keine Bezahlversion. Jede Funktion ist für alle kostenlos. Werbung oder Abos würden die App schlechter machen, deshalb lasse ich sie weg.

Das hier ist ein Ein-Personen-Projekt. Ich habe einen normalen Job und eine Familie und baue das Ganze in meiner Freizeit. Die Server kosten jeden Monat echtes Geld, das ich selbst bezahle. Spenden halten die App online und kostenlos.

Die App ist außerdem Open Source auf GitHub — jeder kann den Code lesen.

Hast du eine Idee für eine Funktion?

Beim Bezahlen gibt es ein optionales Feld „Feature Request“. Schreib deine Idee dort hinein. Ich lese jede einzelne, und Ideen von Spendern bekommen extra Aufmerksamkeit, wenn ich entscheide, was ich als Nächstes baue.

Hall of Fame

Wenn du 5 € oder mehr spendest, kann dein Name hier stehen. Trag deinen Namen oder Alias beim Bezahlen ins Feld „Hall of Fame“ ein. Lässt du es leer, bleibst du anonym. Einen besseren Platz auf der Liste kann man nicht kaufen — jeder Name sieht gleich aus.

Dein Name kann auch auf deine Website verlinken. Schreib die Adresse einfach hinter deinen Namen ins selbe Feld, etwa „Maria (example.com)“. Links sind nofollow, und Links, die nach Werbung aussehen, lehne ich unter Umständen ab.
