이름 배경화면, 이렇게 만들어요

  1. 이름을 입력해요 — 본명, 별명, 이니셜, 마음에 둔 어떤 글자든 좋아요.
  2. 색상과 글자 크기를 골라요 — 취향에 맞는 배경색과 글자색을 고르고, 글자를 원하는 만큼 키워요.
  3. 크기를 정해요 — 휴대폰이나 컴퓨터 화면에 맞는 해상도를 선택해요.
  4. 다운로드해요 — 이미지를 저장하고 배경화면으로 설정하면 끝이에요.

모든 과정이 브라우저 안에서 이루어져요. 입력한 이름은 어떤 서버로도 전송되지 않고, 페이지를 한 번 불러온 뒤에는 인터넷 없이도 작동해요.

휴대폰과 컴퓨터, 알맞은 크기 고르기

  • 휴대폰: 요즘 휴대폰은 보통 1170×2532나 1440×3200 같은 세로 해상도를 써요. 도구가 화면 크기를 자동으로 감지할 수 있어서 대부분은 따로 조절할 필요가 없어요.
  • 컴퓨터: 흔한 크기는 1920×1080(풀HD), 2560×1440, 3840×2160(4K)이에요. 모니터 크기에 맞춰 고르면 글자가 아주 또렷하게 나와요.

팁: 휴대폰에서는 글자를 화면 중앙 근처에 배치하세요 — 잠금 화면에서는 시계가 위쪽을 차지하고, 홈 화면에서는 아이콘이 가장자리를 가려요.

이름 배경화면 아이디어

  • 이름만 — 크고 당당하게, 혹은 작고 은은하게: «지민»은 어느 쪽이든 잘 어울려요.
  • 이니셜 — 두세 글자를 크게 넣으면 모노그램 스타일의 세련된 배경화면이 돼요.
  • 별명 — 친구들이 실제로 부르는 이름이 본명보다 더 멋지게 보일 때가 많아요.
  • 이름 + 짧은 문구 — «서준 — 매일 한 걸음» 같은 한 줄이면 배경화면이 매일의 다짐이 돼요.
  • 이름 + 이모지 — 이름 옆에 별, 하트, 불꽃을 하나 더해 보세요.

무료인 데다 몇 초밖에 안 걸리니, 소중한 사람의 이름으로도 만들어 보세요 — 친구를 위한 작은 선물이나 아이 태블릿용으로도 좋아요.

자주 묻는 질문

무료인가요?

네, 전부요. 회원가입도, 유료 요금제도, 워터마크도 없어요. 원하는 만큼 몇 장이든 만들 수 있어요.

한글과 이모지도 잘 나오나요?

네. 글자를 그리는 건 사용자의 기기이기 때문에 한글의 모든 글자와 이모지가 문제없이 표시돼요.

어떤 해상도로 다운로드되나요?

직접 정한 해상도로요. 다운로드 전에 픽셀 크기를 정하면 이미지가 그 크기 그대로 생성되고, 이후 확대되지 않아요.

워터마크가 있나요?

아니요. 다운로드한 이미지에는 입력한 글자와 선택한 배경색만 들어가요.
